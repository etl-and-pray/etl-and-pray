# Junior Data Analyst

---

## Навыки

- **SQL:** SQLite, Adminer; выборки, JOIN, агрегации, проектирование витрин данных
- **Python:** pandas, NumPy, Jupyter Notebook
- **Статистика и аналитика:** A/B-тесты, проверка гипотез (t-тест, z-тест, ANOVA, хи-квадрат), продуктовые метрики, когортный анализ (retention, heatmap)
- **Визуализация и отчётность:** Power BI, Excel (сводные таблицы), отчёты и презентации по принципу Минто

**Также имеется небольшой опыт работы с:** scikit-learn, Apache Airflow, Docker Compose.

## Проекты

- **[Анализ интернет-магазина спортивных товаров](https://github.com/etl-and-pray/data-analyst-final-project)**
  Итоговый проект курса. Подготовка данных, A/B-тест маркетинговой кампании, сегментация аудитории, восстановление пропущенного пола клиентов с помощью классификации, модель вероятности покупки.

- **[Страхование: сегментация клиентов и ценообразование](https://github.com/etl-and-pray/insurance-pricing-and-segmentation)**
  Кейс по страхованию путешественников (ВЗР). Сегментация клиентов (иерархическая кластеризация, K-Prototypes), A/B-тест тарифов по loss ratio и конверсии, итоговый отчёт по принципу Минто.

- **[Витрина данных для страховой компании](https://github.com/etl-and-pray/insurance-data-mart)**
  ETL-пайплайн: загрузка данных из Excel, конвертация валют через API, сборка единой витрины.

- **[A/B-тест алгоритма прогноза доставки, СберМаркет](https://github.com/etl-and-pray/ab-testing-sbermarket)**
  Статистическая оценка нового алгоритма предсказания времени доставки по данным о поведении пользователей.
