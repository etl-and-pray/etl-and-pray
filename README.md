# Junior Data Analyst

Passionate about data manipulation, building analytical data marts, machine learning, and tracking product metrics. Specialized in transforming raw datasets into clear business insights, effective predictive models, and data-driven management decisions.

---

## Tech Stack & Tools

* **Languages & Libraries:** Python, Pandas, NumPy, Scikit-learn, K-Modes
* **Data & Storage:** SQL, SQLite, Adminer, relational database & data mart design
* **Automation & Pipelines:** Apache Airflow, Docker Compose, ETL pipeline development
* **Statistics & Analytics:** A/B testing, hypothesis testing (t-tests, Z-tests, ANOVA, Chi-square), product metrics calculation, cohort analysis (retention, heatmaps)
* **Visualization & Reporting:** Power BI, Microsoft Excel (pivot tables, advanced statistical metrics), Jupyter Notebook, Minto Pyramid Principle storytelling (PDF reports & presentations)

## Featured Portfolio Projects

Here are key end-to-end projects covering the full analytical lifecycle from exploratory research to business recommendations:

* **[Data Analyst Final Project](https://github.com/etl-and-pray/data-analyst-final-project)**  
  Comprehensive sports store data analysis capstone project. Includes data preprocessing, binary classification (recovering missing customer gender data using ML), A/B testing for marketing campaigns, audience clustering, and purchase propensity modeling.
* **[Insurance Pricing & Segmentation Case](https://github.com/etl-and-pray/insurance-pricing-and-segmentation)**  
  End-to-end insurance analytics case study (Travel Insurance / VZR policies). Combines hierarchical clustering and K-Prototypes for customer segmentation, pricing strategy A/B testing based on loss ratios and conversion rates, and executive reporting structured via the Minto Pyramid Principle.
* **[Insurance Data Mart ETL](https://github.com/etl-and-pray/insurance-data-mart)**  
  Automated ETL pipeline processing Excel files and integrating with currency conversion APIs to build a unified insurance data mart.
* **[SberMarket A/B Testing](https://github.com/etl-and-pray/ab-testing-sbermarket)**  
  Project evaluating delivery prediction algorithms through detailed statistical analysis of user behavior datasets.
